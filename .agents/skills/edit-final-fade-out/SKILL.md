# Edit Final Fade Out

Use this skill for the fifth template effect from `car-edit.mp4`: the ending fade to black.

## Process

1. Place the fade in the final `7-10%` of the output duration unless the user gives a specific timing.
2. Fade the video to black. If audio is present and retained, fade audio too; for the car template sequence, remove audio.
3. QA the final frame. Completion criterion: the last frame is black or nearly black, with no audio tail when the output is supposed to be silent.

Read `references/recipe.md` for timing and output rules.
